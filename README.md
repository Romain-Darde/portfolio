# Portfolio - Romain Darde

Personal portfolio built with Next.js and Tailwind CSS. Features a chronological timeline of my projects (school, internships, personal).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Deployed on Vercel

## Structure

- `lib/projects.ts`: all project data (add a project here, nothing to touch in the components)
- `app/components/`: timeline, project cards, before/after slider
- `public/projects/<slug>/`: images and documents per project
